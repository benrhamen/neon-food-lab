# Pixel Chef

Kawaii pixel cooking game. Real food records and nutrition from USDA SR Legacy (final 2018 release): https://fdc.nal.usda.gov/download-datasets

4,746 USDA entries, grouped into 803 conservative base-name families and 3,943 preparation/cut variants, plus 20 starter shortcuts. Not 4,766 unique raw ingredients. Sprites are original composable category art, not individual portraits. Flavour, texture and method tags are simplified game rules, not a recipe or food safety guide.

Safe cooking reference: https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures
